* Running Codeblocks with =C c C c=

- Each block runs from the repo root
- Each download block asks for the URL at its prompt
- Files land in OUTPUT/VIDEO/ and OUTPUT/AUDIO/ and OUTPUT/SUBTITLE/

* Download with options
#+DESC: download.py with no URL argument and -o OUTPUT
#+PLAIN: Asks for the URL and each option then saves the file.
#+OUTPUT: OUTPUT/VIDEO/ or OUTPUT/AUDIO/ or OUTPUT/SUBTITLE/ by the chosen kind
#+NEXT: open the file in the folder for the chosen kind
#+NAME: download_with_options
#+KIND: manual
#+BEGIN_SRC sh :session cmd :results silent
python3 download.py -o OUTPUT
#+END_SRC

* Update yt_dlp library
#+DESC: apt install --only-upgrade for the yt-dlp package
#+PLAIN: Updates the downloader when a site stops working.
#+OUTPUT: /usr/lib/python3/dist-packages/yt_dlp
#+NEXT: run the Download with options block again
#+NAME: update_yt_dlp_library
#+KIND: build
#+BEGIN_SRC sh :session cmd :results silent
sudo apt update
sudo apt install --only-upgrade yt-dlp
#+END_SRC
