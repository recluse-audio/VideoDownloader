#+TITLE: VIDEO_DOWNLOAD: CMD
#+REPO: VIDEO_DOWNLOAD
#+PATH: VIDEO_DOWNLOAD

* Running Codeblocks with =C c C c=

- Each block runs from the repo root
- Each download block asks for the URL at its prompt
- Files land in OUTPUT/

* DOWNLOAD
#+DESC: download.py with -o OUTPUT at the default best quality
#+PLAIN: Saves one video as an mp4 file.
#+OUTPUT: OUTPUT/<title>.mp4
#+NEXT: open the file in OUTPUT/
#+NAME: download
#+KIND: manual
#+BEGIN_SRC sh :session cmd :results silent
read -r -p "URL: " URL
python3 download.py "$URL" -o OUTPUT
#+END_SRC

* DOWNLOAD_AUDIO
#+DESC: download.py with -q audio and -o OUTPUT
#+PLAIN: Saves only the sound of one video as an mp3 file.
#+OUTPUT: OUTPUT/<title>.mp3
#+NEXT: open the file in OUTPUT/
#+NAME: download_audio
#+KIND: manual
#+BEGIN_SRC sh :session cmd :results silent
read -r -p "URL: " URL
python3 download.py "$URL" -q audio -o OUTPUT
#+END_SRC

* DOWNLOAD_RANGE
#+DESC: download.py with -t START-END and -o OUTPUT
#+PLAIN: Saves one part of a video between two times.
#+OUTPUT: OUTPUT/<title>.mp4
#+NEXT: open the file in OUTPUT/
#+BEFORE: know the start and end time such as 00:01:00-00:02:30
#+NAME: download_range
#+KIND: manual
#+BEGIN_SRC sh :session cmd :results silent
read -r -p "URL: " URL
read -r -p "START-END: " RANGE
python3 download.py "$URL" -t "$RANGE" -o OUTPUT
#+END_SRC

* UPDATE_YT_DLP
#+DESC: apt install --only-upgrade for the yt-dlp package
#+PLAIN: Updates the downloader when a site stops working.
#+OUTPUT: /usr/lib/python3/dist-packages/yt_dlp
#+NEXT: run the download block again
#+NAME: update_yt_dlp
#+KIND: build
#+BEGIN_SRC sh :session cmd :results silent
sudo apt update
sudo apt install --only-upgrade yt-dlp
#+END_SRC
